INSTALL ON ANOTHER WINDOWS LAPTOP

1. Extract this ZIP, then open a terminal in the extracted folder containing src/.
2. Use Python 3.12 to create a new environment:

py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

3. Run the implementation checks:

.\.venv\Scripts\python.exe -m unittest discover -s tests -v

4. Test the saved models using the commands below.
No GPU, training dataset, Colab or retraining is needed for prediction.
Internet is needed for installing dependencies.

VANILLA:
.\.venv\Scripts\python.exe -m src.predict --checkpoint results/gpu_45min/checkpoints/vanilla_class_weight.pt --text "This medicine helped me sleep but caused nausea."

CIFG:
.\.venv\Scripts\python.exe -m src.predict --checkpoint results/gpu_45min/checkpoints/cifg_class_weight.pt --text "This medicine helped me sleep but caused nausea."

WMC:
.\.venv\Scripts\python.exe -m src.predict --checkpoint results/gpu_45min/checkpoints/wmc_class_weight.pt --text "This medicine helped me sleep but caused nausea."

The original owner uses a Conda environment in the parent folder.
Your new environment is a regular venv inside this extracted project.
That explains the different Python paths.
